Tournament Control

Time-based scheduling: The number of rounds is calculated automatically from Start Time → End Time ÷ (Game Time + Score Recording Time). There is no fixed 8-game limit per player. Games are balanced across the available players for the full available time.
Pairing rule: The scheduler avoids repeat partners as a hard priority whenever a valid alternative exists. It then minimizes repeat opponents and balances games.
Schedule Excel and DUPR Excel are separate exports. The DUPR export always remains available, including incomplete data.
